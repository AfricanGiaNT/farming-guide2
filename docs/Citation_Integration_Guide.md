# Citation Integration Guide for AgriAI Companion Business Plan

This guide demonstrates how to integrate the verified references into the business plan using superscript citations. Below are examples of how to cite the references in different sections of the document.

## Executive Summary

### Original Text:
```
Smallholder farmers in Malawi face devastating agricultural challenges that cost millions in lost productivity.
```

### With Citations:
```
Smallholder farmers in Malawi face devastating agricultural challenges that cost millions in lost productivity¹⁴.
```

Where:
- ¹ refers to Reference 1: Malawi Institute of Journalism (2023)
- ⁴ refers to Reference 4: World Bank (2020)
